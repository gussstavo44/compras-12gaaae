# compras-12gaaae
COMO USAR O SCRIPT (API)

para a consulta de LICITAÇÕES

1 - insira a UASG (Unidade Administrativa de Serviços Gerais) do órgão

2 - insira a modalidade da licitação

2-> TOMADA DE PREÇOS
3-> CONCORRÊNCIA
4-> CONCORRÊNCIA INTERNACIONAL
5-> PREGÃO
20-> CONCURSO
99-> RDC

3 - informe a data inicial MM/DD/AAAA

4 - informe a data final MM/DD/AAAA

5 - a licitação pertence à Lei 14133/21 (padrão FALSE)?

6 - escolha o modo de consulta entre 'completos' ou 'todos'

completos-> retorna apenas os registros que tem os campos obrigatorios preenchidos
todos-> retorna todos os registros

7 - informe o máximo de páginas para evitar sobrecarregamento ou falhas (máximo 20)

para a consulta de ITENS DE LICITAÇÃO

OBS: preencha pelo menos um dos filtros para a consulta dos itens de licitação. Insira somente o código do material OU código do serviço

1 - insira a UASG (Unidade Administrativa de Serviços Gerais) do órgão

2 - insira a modalidade da licitação

2-> TOMADA DE PREÇOS
3-> CONCORRÊNCIA
4-> CONCORRÊNCIA INTERNACIONAL
5-> PREGÃO
20-> CONCURSO
99-> RDC

3 - insira o código do item material 

4 - insira o código do item serviço

5 - insira o CNPJ do fornecedor

6 - insira o CPF vencedor

7 - escolha o modo de consulta entre 'completos' ou 'todos'

completos-> retorna apenas os registros que tem os campos obrigatorios preenchidos
todos-> retorna todos os registros

8 - informe o máximo de páginas para evitar sobrecarregamento ou falhas (máximo 20)
